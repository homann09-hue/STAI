# Forecast evaluation

Stand: 2026-08-10

Mature forecasts are evaluated against a verified outcome price. The ledger
does not overwrite the original prediction. Outcomes record whether evaluation
was possible and why data was insufficient when it was not.

Public reporting must include sample size, coverage, evaluation rate, horizon,
model version and uncertainty. Accuracy without those denominators is not a
valid claim. The track-record page is the user-facing evidence surface.
